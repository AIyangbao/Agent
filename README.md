# 大一下起步基于哔哩哔哩黑马学习agent开发做的demo
本人大一下期间完成的agent,RAG入门项目

### 核心技能模块
### 1. RAG
- 技术栈:Python、langchain、OpenAI、qwen3、chroma、streamlit、ReAct
- 核心内容:智能服装客服、智扫通机器人客服
- 日记:2026年3月份,大一下学期有很多空闲的时间，去看了看黑马的视频，质量的确不错，国内b站大学也是名副其实了，大一下没有专业课，基本都是理论课，打算跟着黑马系统学习一下agent相关的开发技术栈，智能服装客服(GAG项目案例),智扫通机器人客服(大模型RAG与智能体开发_Agent项目)都是基于streamlit运行的,感觉项目较浅,后面打算系统学习一下后端知识.

- 2.后端开发
- 技术栈:Python、ORM、FastAPI、MySQL、Redis、vue3、node.js、阿里云
- 核心内容:toutiao_news
- 日记:2026年4月份跟着黑马学习了FastAPI,大致学习了后端接口开发的具体流程,用ORM实现CURD倒是熟悉了,相比pymysql,ORM更安全方便些,不用自己写SQL指令,也防止了SQL注入问题,前端代码是直接拿黑马给的现成的,目前还是对前后端交互这一片空白,也是因为前端只写过简单的html和css缘故吧,为了学业能达标,进度并不快,稳打稳扎便好.
2026年5月份白嫖了阿里一个月免费的服务器,阿里服务器初始化的CentOS系统和自带宝塔老版本用得真不舒服，折腾一天失败了,重装了下服务器系统用上了比较习惯的Ubuntu,部署了宝塔将这个头条项目部署到服务器上,新手学命令行还是挺折腾的,可惜了域名白嫖不了。

- 3.dify
- 技术栈:Docker、FastAPI、阿里云
- 核心内容: dify_work_api
- 日记: 2026年5月份跟着黑马视频部署了下dify,因为看市场的确有相关需求,不得不说docker也挺折腾的,刚开始因为用的是老电脑旧Window版系统无法兼容新版DockerDesktop,后面尝试了wsl部署也因为兼容问题卡住了,最后还是更新系统尝试了一番，折腾大概也对docker有了简单的了解和应用,中途因为拉取镜像老是因网络问题超时，向豆包找了合适的国外镜像源,说到底dify就是拉取打包好的镜像基于docker在本地服务器运行的开发平台,在平台做了些基础的demo,图形化的开发对于新人而言较为友好,dify市场上接口集成也很多,个人觉得侧重于快速产出Agent,但离开了代码的精确性,这开发出来的产品维护和扩展性会高吗?对图形化的编程没啥热情,但还是继续走个学习流程,用FastAPI复现了黑马的天气查询接口,并用docker进行了容器化,部署到阿里云服务器上,完整走了一遍dify插件制作流程.
